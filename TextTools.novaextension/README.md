# digiSTART Text Tools

Editorial utilities for Panic Nova.

## Commands

- `RAE: Formatear comillas para Markdown`
- `WordPress: Convertir selección a permalink`

These commands operate on the current editor selection. Multiple selections are supported.

## Installation

1. Download the latest release from the repository.
2. Unzip the downloaded file.
3. In Nova, choose `Extensions > Activate Project as Extension...`.
4. Select the `TextTools.novaextension` folder.
5. Run the commands from Nova's `Editor` menu.
